# AGENT INSTRUCTIONS & ARCHITECTURE GUIDE (.agents.md)

This repository contains the official personal portfolio and architecture showcase for **Sunil Parajuli** (Solution Architect & Health Informatics / Social Protection Specialist).

---

## 🏗️ 1. Tech Stack & Architecture

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript (`strict: true`, ESNext)
- **Styling**: Tailwind CSS with custom Swiss editorial design tokens
- **Typography**: `@next/font` & Google Fonts (Plus Jakarta Sans, Outfit, JetBrains Mono)
- **Icons**: `lucide-react`
- **Dynamic OG Image**: Next.js Edge Runtime `ImageResponse` (`src/app/opengraph-image.tsx`)
- **SEO**: Dynamic `sitemap.ts`, `robots.ts`, `manifest.ts`, and Schema.org JSON-LD structured data (`StructuredData.tsx`)
- **Deployment Target**: Vercel (Static Prerendered) + Cloudflare DNS

## 🎨 3. Design System & Aesthetics

The design is modeled after a **Swiss Minimalist / Architectural Editorial** aesthetic:

- **Light Mode Palette**:
  - Background: `#FAF8F5` (Warm limestone paper)
  - Foreground: `#182623` (Deep carbon slate ink)
  - Accent: `#E05A36` (Terracotta / Coral flame)
  - Secondary: `#F0EDE6` (Sand neutral)
  - Border: `#DDD8CD` (Subtle architectural line)
- **Dark Mode Palette (`.dark`)**:
  - Background: `#0B100E` (Deep obsidian / slate)
  - Foreground: `#F2EFE9` (Ivory white)
  - Accent: `#E86644` (Vibrant terracotta)
  - Secondary: `#17221E` (Dark spruce)
  - Border: `#23312C`
- **Typography Rules**:
  - Headlines: Tight tracking (`tracking-[-0.075em]`, `font-semibold`)
  - Subheaders / Tags: Monospace uppercase (`font-mono text-xs uppercase tracking-[.18em]`)
  - Wireframe Accents: Square corner anchor blocks (`size-4 bg-accent`) and geographic coordinates (`27°42'N / 85°19'E`).

## 🔄 4. How to Modify Content (Single Source of Truth)

All text, project details, metrics, work history, and academic information live inside [`src/data/portfolioData.ts`](src/data/portfolioData.ts).

### To Add a New Project:
Append an object to `featuredProjects` array in `portfolioData.ts`:
```typescript
{
  id: "unique-slug",
  title: "Project Title",
  subtitle: "Subtitle / Context",
  client: "Client / Organization",
  organization: "Partner Organization",
  location: "City, Country",
  period: "Year / Date",
  role: "Your Role Title",
  category: "health-informatics" | "interoperability" | "social-protection" | "enterprise",
  summary: "1-2 sentence summary for the card tile",
  overview: "Detailed architecture overview for the deep-dive modal",
  keyResults: ["Bullet 1", "Bullet 2", "Bullet 3"],
  technologies: ["Tech1", "Tech2", "Tech3"],
  metrics: [{ label: "Metric Label", value: "Value" }],
  link: "https://optional-external-link.com",
  linkText: "Button Label"
}
```

### To Update CV PDF:
Place the new PDF file at [`public/Sunil_Parajuli_CV.pdf`](public/Sunil_Parajuli_CV.pdf). All download buttons point to this static path.
